下一步工作流

  1. 在 ~/Projects/szbolent-portal 改前端代码（src/views、src/api 等）
  2. cd ~/Projects/szbolent-portal && npm install && npm run build
  3. 把 nginx 配置的 root 改成 /Users/jason/Projects/szbolent-portal/dist
  4. 访问 / 看真 SPA
  5. 跑 ~/Projects/szbolent-portal/scripts/test-local.sh 全套烟雾测试
  6. 确认通过后 git push origin main 触发腾讯云部署

关键文件

  • deploy-local/docker-compose.local.yml — 3 容器编排
  • deploy-local/nginx/szbolent-portal-local.conf — nginx 站点配置
  • deploy-local/dist-stub/index.html — 占位首页（本文件）
  • deploy-local/looma-stub/app.py — looma 占位 Flask
